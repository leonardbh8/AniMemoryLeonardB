Bienvenue sur le site de Memory Game de l'ENI !
Venez jouer à notre jeu de mémoire !


Les règles du jeu :

  • Retournez les cartes si le jeu laisse les cartes visibles c'est gagné !
  • Si les images sont différentes, c'est perdu et les images se retournent de manière cachés là ou elles etaient.
  • La partie se termine lorsque toutes les paires de cartes ont été trouvées.




Si vous voulez vous souvenir de votre score, inscrivez-vous.
Le jeu garde vos 5 meilleurs scores.
Si vous voulez relancer une partie, cliquez sur la barre espace.
